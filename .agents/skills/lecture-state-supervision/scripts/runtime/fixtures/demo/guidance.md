# Episode 13 supervision sandbox guidance

This fixture is not production content.  It exists to exercise exact context
delivery, independent review, human gates, change routing, gap handling, and
incremental Web updates before the real Episode 13 run.

Workers must stay inside the assigned task and submit only the named artifact
roles.  Missing inputs are reported through `gap`; scope changes go through
`change`.  Notes alone do not count as meaningful progress.
